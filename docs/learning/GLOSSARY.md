# 📖 Terminology & Technical Glossary — FITMENT.AI

> **Audience**: All Users, Engineers, Recruiters, and Solutions Architects.  
> **Last Reviewed**: 2026-10-19  

---

### A
- **Authoritative Determinism**: An architectural principle where compliance-critical calculations (such as candidate fitment scores, seniority depth, and skill matching) are computed purely through deterministic algorithms (Python regex, token sets, mathematical weights) rather than probabilistic generative models.

### C
- **Candidate Fitment Score**: An integer score between 0 and 100 representing the mathematical match between a candidate's resume and a job description, computed as:
  $$\text{Score} = 0.30 \cdot S_{\text{skills}} + 0.40 \cdot S_{\text{exp}} + 0.15 \cdot S_{\text{edu}} + 0.15 \cdot S_{\text{certs}}$$
- **Candidate Summary Strip**: A high-density visual component in the Screening Workspace displaying candidate name, normalized mobile, email, location, current employer, designation, and tenure immediately upon resume parsing.
- **Content-Addressable Deduplication**: A file storage technique where files are indexed by their cryptographic SHA-256 digest (`sha256_hash`). If an identical file is uploaded twice, the existing storage record is reused, eliminating duplicate disk usage.

### D
- **Deferred Pending Navigation**: A safe Streamlit pattern where button callbacks set `st.session_state.pending_nav` and invoke `st.rerun()`, allowing the target view to be applied before the sidebar navigation radio widget is instantiated. Prevents `StreamlitWidgetAlreadyInstantiatedError`.
- **Dossier**: A comprehensive, standalone markdown report (`Candidate_Fitment_Dossier_<Name>.md`) generated by the platform containing candidate metadata, fitment score, matched skills with quotes, missing skills, and interview probing questions.

### F
- **FastMCP**: A lightweight Python library for implementing the Model Context Protocol (MCP), enabling external LLMs (e.g. Claude Desktop) to invoke FITMENT.AI candidate screening tools natively.
- **Fitment Assistant**: The conversational companion panel (`chatbot.py`) operating in the right workspace (~26% width), capable of answering candidate database queries (Mode A) and general technical questions (Mode B).

### I
- **Indian Standard Time (IST, UTC+05:30)**: The official standardized timezone (`Asia/Kolkata`) enforced across FITMENT.AI for live clock displays, screening timestamps, and daily calendar-day recruitment analytics.
- **InstantFit**: The platform's proprietary offline screening engine that evaluates candidate fitment with zero external network calls or cloud API dependencies.

### M
- **Mode A (Candidate Grounded Intelligence)**: The chatbot operating mode where inquiries regarding registered candidates are resolved exclusively through parameterized SQL queries against the local SQLite database.
- **Mode B (General Technical Copilot)**: The chatbot operating mode where generic engineering or protocol questions without candidate references are routed to external cloud LLMs.

### R
- **Recruitment Lifecycle Stages**: The 11 formal pipeline stages tracked in FITMENT.AI:
  1. `New`
  2. `Screened`
  3. `Shortlisted`
  4. `Recruiter Review`
  5. `Interview Scheduled`
  6. `Interview Completed`
  7. `On Hold`
  8. `Rejected`
  9. `Selected`
  10. `Offer Released`
  11. `Joined`
- **Relational Grounding (SQL-Augmented Generation)**: Using relational database tables and foreign keys to supply ground truth context to conversational AI, ensuring 100% precision on contact details and scores compared to chunk-based Vector RAG.

### S
- **Screening Files Junction Table**: The SQLite relational table (`screening_files`) linking `screenings` to `stored_files` in a many-to-many relationship, permitting one Job Description to be screened against dozens of resumes without duplicate storage.
- **STRIDE**: The industry-standard threat modeling framework (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege) used to evaluate and harden platform security.

### Z
- **Zero-Hallucination Invariant**: A platform guarantee that numerical fitment scores, candidate phone numbers, and educational credentials are never generated by generative AI token prediction.
